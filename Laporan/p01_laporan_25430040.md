**4. Jawaban Titik Analisis**



Titik Analisis 1: Label tombol di XAMPP adalah "MySQL", padahal yang berjalan adalah MariaDB. Konsekuensinya, saat mencari solusi error di internet, kita harus merujuk ke dokumentasi MariaDB karena fitur baru MariaDB mungkin tidak sama lagi dengan MySQL.



Titik Analisis 2: Saat masuk dengan mysql -u root tanpa opsi -p, pesan galat menunjukkan (using password: NO), yang artinya klien tidak mengirimkan password sama sekali ke server.



Titik Analisis 3: information\_schema tetap terlihat karena itu adalah basis data sistem yang berisi informasi struktur tabel (kamus data sistem) yang boleh dibaca pengguna. Sedangkan akses ke mysql ditolak dengan ERROR 1044. Beda ERROR 1044 dengan 1045 adalah: 1044 berarti login berhasil tapi hak akses ke basis data ditolak, sedangkan 1045 berarti login (username/password) itu sendiri yang ditolak.



Titik Analisis 4: Mode cookie di phpMyAdmin lebih aman karena pengguna dipaksa mengetik password setiap kali login. Pada mode config, password disimpan secara plain text di dalam file config.inc.php yang sangat rentan dicuri.
